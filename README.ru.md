## Обзор

**Horreum** — это высокопроизводительная распределенная система кеширования типа key-value, разработанная с использованием архитектуры с нулевым выделением памяти (zero-allocation) на горячем пути. Сервис построен на основе mmap-арен, FIFO-очередей вытеснения S3-FIFO, быстрой LZ4-компрессии на чистом Go и аутентифицированного шифрования AES-256-GCM. Horreum обеспечивает микросекундные задержки и полностью исключает нагрузку на сборщик мусора (GC) при работе с данными.

## Ключевые возможности

- **Zero-Allocation на горячем пути**: Кастомный mmap-аллокатор арен (`internal/arena`) и указатели `unsafe.Slice`. Полное отсутствие нагрузки на сборщик мусора (GC).
- **Вытеснение S3-FIFO**: Безблокировочные операции Touch через атомарные счетчики частоты и две кольцевые очереди (Small и Main), превосходящие по эффективности классический LRU.
- **Двойной транспортный уровень**: 
  - **TCP**: Маршрутизатор с привязкой соединений (connection-pinning) по хешу `(remoteIP + localPort)` к воркерам шардов.
  - **QUIC**: Нативная поддержка мультиплексирования стримов по TLS 1.3 на базе `quic-go`.
- **LZ4-компрессия на чистом Go**: Опциональное ультрабыстрое сжатие значений с переиспользованием буферного пула, достигающее **~2 ГБ/с** на декомпрессии.
- **Аутентифицированное шифрование at rest**: AES-256-GCM AEAD шифрование с авто-генерацией 32-байтного ключа (**~4.9 ГБ/с** скорость дешифрования через AES-NI).
- **YAML-конфигуратор (Stdlib Only)**: Парсер конфигурации на чистом Go без внешних зависимостей, поддерживающий бинарные размеры (`256MiB`, `1GiB`).
- **Низкозатратное логирование**: Структурированный логгер `log/slog` с лимитированием сообщений (rate-limiting) и отслеживанием медленных синхронизаций WAL (slow log).
- **Надежная персистентность**: Write-Ahead Logging (WAL) с холодным реплеем и атомарным сохранением контрольных точек HashIndex.

## Быстрый старт

### Локальная сборка и запуск

```bash
# Сборка бинарного файла
go build -o horreum ./cmd/horreum

# Запуск с конфигурационным файлом YAML
./horreum --config config.yaml
```

### Запуск в Docker

```bash
# Сборка Docker-образа
docker build -t horreum:latest .

# Запуск контейнера
docker run -d -p 7373:7373 -p 9090:9090 --name horreum horreum:latest
```

## Примеры клиентов

Horreum использует бинарный протокол кадрирования с 10-байтным заголовком. Готовые клиенты находятся в директории [`examples/`](file:///e:/pet/horreum/examples/):

- [Python Client](file:///e:/pet/horreum/examples/client.py)
- [Node.js Client](file:///e:/pet/horreum/examples/client.js)
- [Go Client](file:///e:/pet/horreum/examples/client.go)

### Пример на Python

```python
from examples.client import HorreumClient

client = HorreumClient('127.0.0.1', 7373)
client.connect()

# Запись значения
client.set("user:1001", "Alice")

# Чтение значения
val = client.get("user:1001")
print("User:", val.decode())

client.close()
```
