## [1.0.0] - 2026-07-29

### Добавлено
- **Ядро и Управление Памятью**:
  - Арена-аллокатор на базе mmap (`internal/arena`) на чистом Go с bump-аллокатором и изолированными фрилистами (segregated freelist).
  - Политика вытеснения S3-FIFO (`internal/eviction`) с атомарными счетчиками частоты и кольцевыми очередями (Small и Main).
  - Хеш-индекс открытой адресации (`internal/index`) с квадратичным пробированием.
- **Транспорт и Сетевой Уровень**:
  - TCP сервер (`internal/transport/tcp`) с привязкой соединений (connection-pinning) по хешу `(remoteIP + localPort)`.
  - QUIC сервер (`internal/transport/quic`) с поддержкой мультиплексирования стримов по TLS 1.3 на базе `quic-go`.
  - Парсер 10-байтного бинарного протокола кадрирования с нулевым выделением памяти (`internal/proto`).
- **Защита Данных и Сжатие**:
  - Кодек LZ4 компрессии (`internal/compress`) на чистом Go с пулом буферов.
  - Аутентифицированное шифрование at rest (`internal/encrypt`) на базе AES-256-GCM с генерацией случайного 12-байтного IV.
  - Автоматическая генерация 32-байтных ключей через флаг `--keygen` и авто-создание файла ключа при старте.
- **Логирование и Конфигурация**:
  - Парсер YAML на чистом Go (`internal/config`) с поддержкой размерностей памяти (`256MiB`, `1GiB`).
  - Структурированное логирование `log/slog` (`internal/logger`) с лимитированием сообщений (rate-limiting) и slow log для WAL sync.
- **Клиенты и Окружение**:
  - Готовые клиенты на Python (`examples/client.py`), Node.js (`examples/client.js`) и Go (`examples/client.go`).
  - Продакшн `Dockerfile` и шаблон `config.yaml`.
  - Интеграция экспортера метрик Prometheus (`internal/metrics`).

### Исправлено
- **Координатор завершения (Shutdown)**: Устранена проблема немедленного выключения сервера при старте.
- **Совместимость с Windows mmap**: Добавлена безопасная эмуляция выделения памяти для не-Linux платформ.
